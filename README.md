# 🚚 Haul Empire

A mobile-first trucking idle game. Tap the road to drive deliveries, build a fleet that hauls while you're away, catch rush orders, and push your routes from Main Street to the Moon.

**Play:** https://kurtztech.github.io/haul-empire/

- 10 vehicles, from a beat-up pickup to Hyperfreight Pods, with ×2 milestones
- 7 routes with their own scenery and day/night cycle
- Tap combos, rush orders (cash, Tailwind, Nitro), auto-dispatch
- 80+ upgrades, 25 achievements, and an IPO prestige system
- Offline earnings and automatic saves (localStorage)

Single file, no build step — just `index.html`.
